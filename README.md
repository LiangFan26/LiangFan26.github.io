# Publish LiangFan26.github.io

1. Sign in to GitHub as `LiangFan26`.
2. Create a **public** repository named exactly `LiangFan26.github.io`.
3. Upload `index.html` and `.nojekyll` from this folder to the repository root and commit the files.
4. In the repository, open **Settings → Pages**. If needed, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Visit `https://LiangFan26.github.io` after GitHub Pages finishes deploying.

The page is a static site and needs no build step. Later updates can be made by editing `index.html` and committing the change.
